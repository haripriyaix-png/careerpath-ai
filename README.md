# CareerPath AI

AI-Powered Career Roadmap Generator — MIT-ADT University, Group TYAIA809.

## Stack
React + Vite, Tailwind CSS, Recharts, Lucide React, Python Flask, SQLite.

## Run

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Backend: http://127.0.0.1:5000

### Frontend
Open a second terminal:
```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL, normally http://localhost:5173.

## Demo
Click "Try demo profile" on the landing page. It loads a third-year B.Tech CSE/Cybersecurity profile targeting Cybersecurity Analyst.
